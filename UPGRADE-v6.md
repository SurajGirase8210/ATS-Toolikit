# ATS Toolkit v6

Enhanced resume editing and application companion release.

## Resume Builder
- Add custom sections with arbitrary titles.
- Hide/delete built-in sections and restore hidden sections.
- Reorder built-in sections.
- Reorder custom sections.
- Save as a new resume version without overwriting the current version.
- Content repetition heuristic.
- ATS change approval workflow.
- Direct Cover Letter companion link.

## Research-informed additions
The feature direction follows current resume-builder patterns: job-specific tailoring, versioning, accept/discard edits, section reordering, cover letters, and clear ATS feedback. It intentionally avoids fabricating experience or metrics.
